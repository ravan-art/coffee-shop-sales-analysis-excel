# ☕ Coffee Shop Sales Analysis | Excel

## 📌 Project Overview

This project analyzes **149K+ coffee shop transaction records** to understand sales performance, customer ordering patterns, peak sales periods, store performance, and product performance.

The analysis was performed using **Microsoft Excel and Power Query**, with PivotTables, PivotCharts, KPIs, and interactive slicers used to build an interactive sales analysis dashboard.

---

## 🎯 Business Objectives

The main objectives of this project were to:

* Analyze overall sales performance
* Identify revenue trends
* Identify peak sales periods
* Analyze store-level performance
* Identify top-selling products
* Understand customer ordering patterns
* Support staffing and inventory planning decisions

## 🔄 Data Cleaning & Transformation

The raw transaction data was cleaned and transformed using **Power Query**.

The main steps included:

* Removing unnecessary records
* Handling missing values
* Correcting data types
* Cleaning and transforming transaction data
* Creating calculated fields
* Extracting month, day, and hour information
* Preparing the dataset for analysis

## 📈 Analysis Performed

### 1. Sales Trend Analysis

Analyzed sales performance across:

* Months
* Days
* Hours
* Peak sales periods

### 2. Store Performance

Compared sales performance across different store locations to identify high-performing and low-performing stores.

### 3. Product Performance

Analyzed:

* Top-selling products
* Product-level sales
* Product contribution to overall sales

### 4. Customer Ordering Patterns

Analyzed transaction patterns to understand when customers place orders and identify periods of high demand.
